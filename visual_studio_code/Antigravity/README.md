## ⚡ El Trío Maestro de Atajos de Pantalla

| Atajo (Win/Linux) | Atajo (macOS) | Panel que Controla |
| :--- | :--- | :--- |
| **`Ctrl + B`** | `Cmd + B` | **Mostrar / Ocultar Barra Lateral Izquierda** (Explorador / Git / Extensiones) |
| **`Ctrl + Alt + B`** | `Cmd + Option + B` | **Mostrar / Ocultar Barra Lateral Derecha** (Panel del Agente Antigravity) |
| **`Ctrl + J`** | `Cmd + J` | **Mostrar / Ocultar Panel Inferior** (Terminal / Problemas / Salida sin matarla) |
| **`Ctrl + I`** | `Cmd + I` | **Edición Asistida In-Place** (Comando flotante sobre selección) |
| **`Tab`** | `Tab` | **Aceptar Autocompletado Predictivo** (*Antigravity Tab*) |
