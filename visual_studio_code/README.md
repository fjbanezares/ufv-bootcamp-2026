## ⚡ Chuleta Rápida de Atajos Esenciales

| Acción | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **Paleta de Comandos** | `Ctrl + Shift + P` | `Cmd + Shift + P` |
| **Búsqueda Rápida de Archivos** | `Ctrl + P` | `Cmd + P` |
| **Mostrar / Ocultar Barra Lateral** | `Ctrl + B` | `Cmd + B` |
| **Abrir / Cerrar Terminal Integrada** | `Ctrl + \`` | `Cmd + \`` |
| **Buscar en Todo el Proyecto** | `Ctrl + Shift + F` | `Cmd + Shift + F` |
| **Multicursor por Siguiente Coincidencia** | `Ctrl + D` | `Cmd + D` |
| **Mover Línea Arriba / Abajo** | `Alt + ↑ / ↓` | `Option + ↑ / ↓` |
| **Duplicar Línea Arriba / Abajo** | `Shift + Alt + ↑ / ↓` | `Shift + Option + ↑ / ↓` |
| **Comentar / Descomentar Línea** | `Ctrl + /` | `Cmd + /` |
| **Renombrar Símbolo en Todo el Proyecto** | `F2` | `F2` |
| **Iniciar Depuración (Run & Debug)** | `F5` | `F5` |
| **Dividir Editor en Dos** | `Ctrl + \` | `Cmd + \` |
