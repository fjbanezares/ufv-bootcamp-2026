# Módulo Python

Este directorio agrupa todo el material, ejercicios y proyectos desarrollados en Python.

## Estructura
- **`training/`**: 27 bloques temáticos que cubren desde los fundamentos de la sintaxis hasta librerías avanzadas:
  - Tipos primitivos, variables, cadenas y condicionales.
  - Estructuras de datos (listas, tuplas, diccionarios, sets).
  - Programación Orientada a Objetos (OOP) y persistencia.
  - Manipulación y análisis de datos: **NumPy**, **Pandas**, **Matplotlib**.
  - Integración con APIs modernas (Gemini API, ChatGPT, Resend).
  - Minijuegos con **Turtle** (Pong, Snake, carreras de tortugas).
- **`algorithms/`**: Implementaciones de algoritmos y funciones de lógica (ej. paridad, ejecuciones principales).
- **`blockchain/`**: Implementación de una arquitectura y prototipo de cadena de bloques.
- **`collections/`**: Ejercicios y fundamentos de diccionarios, listas y sets.
- **`types/`**: Ejemplos específicos de tipado básico y enteros grandes en Python.
- **`tutorial_turtle/`**: Primeros pasos y carreras con Turtle graphics.
- **`my_package/`**: Estructura de paquetes y configuración con `setup.py`.
- **`data/`**: Datasets y archivos de recursos (`.csv`, `.txt`, imágenes de gráficos).
