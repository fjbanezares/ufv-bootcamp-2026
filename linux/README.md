# Módulo Linux

Espacio dedicado a comandos, automatización mediante scripts de Shell / Bash, administración del sistema y buenas prácticas en entornos Linux / UNIX.

## Contenido
- **`scripts/`**: Scripts de automatización, tareas del sistema y despliegue (ej. `resource_management_example.sh`).
- Chuletas de comandos esenciales (navegación, permisos, procesos, redes y pipes).

## Comandos Esenciales de Referencia Rápida
- **Navegación y archivos**: `ls -lah`, `cd`, `pwd`, `cp -r`, `mv`, `rm -rf`, `mkdir -p`
- **Permisos y usuarios**: `chmod +x script.sh`, `chown user:group archivo`
- **Búsqueda y texto**: `grep -rn "patron" .`, `find . -name "*.py"`, `cat`, `less`, `tail -f`
- **Procesos y recursos**: `ps aux`, `top` / `htop`, `kill -9 <PID>`
