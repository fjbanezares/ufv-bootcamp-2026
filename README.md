# UFV Bootcamp 2026

Repositorio central con recursos, ejercicios y proyectos del **Bootcamp UFV 2026**. Organizado de forma modular en 5 áreas principales de desarrollo y sistemas:

```
.
├── 📁 intro/              # Mentalidad, síndrome del impostor, uso de IA en estudio y cloud
├── 📁 visual_studio_code/ # Entorno de desarrollo, atajos ninja, Git visual y depuración
├── 📁 linux/              # Scripts Shell/Bash, automatización y administración de sistemas
├── 📁 git/                # Guías de control de versiones, comandos y flujo colaborativo
├── 📁 python/             # Formación completa en Python (sintaxis, datos, POO, APIs, mini-juegos)
└── 📁 sql/                # Bases de datos relacionales, consultas y persistencia
```

---

## 🗂️ Estructura del Repositorio
 
### 🚀 [0. Intro & Mentalidad](./intro/)
Superación del síndrome del impostor, uso pedagógico de herramientas de IA y mentalidad de aprendizaje técnico.
- Guía interactiva de debate: **El Fantasma en la Pantalla Negra**.
- Serie visual de 9 infografías anti-impostor.
- Buenas prácticas de Inteligencia Artificial para el estudio.

### 💻 [1. Visual Studio Code](./visual_studio_code/)
Dominio del editor de desarrollo líder de la industria y entorno de programación del bootcamp.
- **[Curso Profundo: Visual Studio Code (Manual Interactivo)](./visual_studio_code/CURSO_VISUAL_STUDIO_CODE.md)**.
- **Infografía Visual Oficial**: Anatomía, atajos clave, extensiones recomendadas y depuración.
- **Laboratorios Prácticos**: Práctica y juego interactivo con Git visual, diff por rangos, resolución de conflictos y debugging con breakpoints.

### 🐧 [2. Linux](./linux/)
Comandos esenciales de la terminal, gestión de procesos, permisos y scripts de automatización en Bash.
- Script de gestión de recursos en nube / bash.
- Chuleta de comandos y utilidades UNIX.

### 🌿 [3. Git & GitHub](./git/)
Control de versiones profesional, flujo de trabajo en equipo y arquitectura interna.
- **[Curso Profundo: Git Desde Cero (Manual con Mini-Prácticas)](./git/CURSO_GIT_DESDE_CERO.md)**.
- **Serie Visual de 10 Infografías**: De la máquina del tiempo a *rebase interactivo* y *internals*.
- **Práctica Inception**: Ejercicio colaborativo con ramas, merge y resolución de conflictos.

### 🐍 [4. Python](./python/)
El núcleo de programación del bootcamp con más de 25 bloques temáticos y proyectos prácticos:
- **`training/`**: Fundamentos, estructuras de datos, programación orientada a objetos, `numpy`, `pandas`, `matplotlib` e integraciones con APIs (Gemini, ChatGPT, Resend).
- **`algorithms/`**: Algoritmos de lógica y resolución de problemas.
- **`blockchain/`**: Prototipo y arquitectura de cadena de bloques.
- **`tutorial_turtle/`**: Juegos clásicos (Snake, Pong, carreras).
- **`my_package/`**: Empaquetado y distribución modular en Python.
- **`data/`**: Datasets y archivos de soporte (`.csv`, `.txt`).

### 🗄️ [5. SQL](./sql/)
Diseño, manipulación y consulta de bases de datos relacionales:
- Ejemplos prácticos de integración SQLite con Python (`basic-example.py`).
- Scripts y consultas para manipulación de esquemas y datos.
