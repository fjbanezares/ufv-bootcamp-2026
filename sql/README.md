# Módulo SQL & Bases de Datos

Espacio dedicado a consultas SQL, modelado relacional, scripts de migración y conectividad desde Python (SQLite, PostgreSQL, MySQL).

## Contenido
- **`basic-example.py`**: Conexión y operaciones CRUD básicas sobre SQLite desde Python.
- **`example.db`**: Base de datos SQLite local para pruebas y prácticas.

## Conceptos Clave
- **DDL (Data Definition Language)**: `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`.
- **DML (Data Manipulation Language)**: `SELECT`, `INSERT INTO`, `UPDATE`, `DELETE FROM`.
- **Cláusulas y Agregaciones**: `WHERE`, `ORDER BY`, `GROUP BY`, `HAVING`, `JOIN` (INNER, LEFT, RIGHT).
