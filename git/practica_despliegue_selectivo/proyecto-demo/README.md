# Proyecto Demo: Mi Libro

Este directorio representa el **repositorio maestro completo** (el taller de trabajo):
- Contiene fuentes de maquetación (`latex/`), archivos pesados (`pdf/`), borradores de traducciones (`traducciones/`) y utilidades internas (`herramientas/`).
- La carpeta `web/` contiene la versión para producción que se publicará mediante despliegue selectivo.
